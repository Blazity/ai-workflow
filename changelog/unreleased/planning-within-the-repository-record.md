- A planning run that asks for a repository it cannot have now costs one extra pass, not five. The run plans with the repositories it does hold and writes what it could not do without the others into the plan, naming each one, the agent's own reason for wanting it and the run's reason for refusing it. A ticket naming four repositories where somebody answered "just the API" ends with a plan for the API instead of a failed run.
- The ticket comment on such a run reaches a person whole, with the way back still in it. It used to be cut through the middle, so the repository, the reason and the action were all in the part that was removed.
- A run never tells somebody to select a repository nobody has enabled, which is refused, or to enable one that is already enabled. Each reason now names the move that actually works: the Repositories page, this work's repository list, or the provider.
- The planning prompt no longer threatens to end the run on a repeated request, because it does not, and it says on the pass that binds that this is the last one a repository request buys.
- The prompt no longer tells an agent that older clarification rounds were left out when what really happened is that the newest round's own question and answer were shortened. It says which of the two happened, and how much.
