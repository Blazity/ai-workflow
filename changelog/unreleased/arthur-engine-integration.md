- The Arthur Engine is now an integration. It appears on the Integrations page with its own card, its checks on System health, and its own section in the sidebar once it is connected, where Evals moved from the top-level menu; links to the old Evals address land on the new page, and the Overview page shows errors where the eval score tile was. Deployments that configured it through `GENAI_ENGINE_API_KEY` and `GENAI_ENGINE_TRACE_ENDPOINT` keep working with nothing to change, disabling it from the dashboard takes its blocks out of the editor palette everywhere at once, and its key now goes only to the tracer inside an agent sandbox, not into the environment the agent and its commands inherit.
- The Prompt injection check reports a screening result or stops the run, and never reports that it did not look. With nothing bound it screens the ticket's description and comments, and the editor says so on the field; a run with neither stops and asks for the content to be bound. Publishing a workflow in which nothing reads the check's status is refused, naming the block, so every flagged prompt leads somewhere the author chose. If the engine cannot be reached, cannot open a task, or evaluates no rule, the run stops with the reason, and a workflow that uses the block on a deployment where Arthur is disconnected or disabled fails at the start, naming Arthur.
- Runs waiting on a person are cancelled before this version is deployed, and each cancelled run's ticket gets a comment asking to move it back into the AI column once the deploy is done. Workflows are paused for the deploy and resume after it.
