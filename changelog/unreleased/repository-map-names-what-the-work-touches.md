- The repository map an agent receives names the repositories this work touches and the ones it can use, and covers everything else in one sentence: any repository the map does not name is closed to the work and asking for it changes nothing. The names and descriptions of repositories nobody enabled and nothing on the work refers to stay inside AI Workflow instead of travelling to a model, and the map keeps the same size whether a provider account holds five repositories or five hundred.
- Where the map describes a repository in the words somebody wrote on the Repositories page, and where it says how one repository relates to another, it says so on the line: that text is recorded there and is not checked against the code. An agent reading it has what it needs to confirm a relationship before writing it into a pull request as a fact.
