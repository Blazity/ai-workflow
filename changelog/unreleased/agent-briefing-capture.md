- A run keeps what each of its agents was given: every model send records the prompt it was sent, section by section, with where each part came from, what the prompt held back, the model and profile behind it, and the repositories in scope. A briefing is kept for thirty days from its own send, and for as long as the run's replay where that is longer, so a run parked awaiting an answer still has the briefing of the send it resumed with.
- A new setting, agent briefings, turns that recording off for the next run; a send made while it was off is marked as such, so a run that recorded nothing is never confused with one nobody kept.
