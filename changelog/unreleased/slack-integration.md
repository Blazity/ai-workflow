- Slack is an integration: connect it on the Integrations page or keep the `CHAT_SDK_*` and `SLACK_*` variables you already have, and `/ai-workflow` answers at the same address in the same threads. "Send Slack message" is now "Send message" and works through whichever messaging integration is connected; saved workflows keep running and open as the new block.
- Send message reports success only for a message that arrived, and otherwise reports skipped with the reason, which a workflow can branch on. A deployment with no messaging integration still runs its workflows, and a block that needs one names what to connect before any work starts.
