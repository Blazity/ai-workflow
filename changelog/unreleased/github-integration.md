- GitHub is an integration: connect it on the Integrations page or keep the environment variables you already have, and the App keeps posting to the same webhook URL. The Connection form takes the App's private key as a pasted `.pem` file or as base64, and a deployment with only part of its GitHub values set starts and names the missing one on the Integrations page.
- The GitHub card on the Integrations page checks the App itself: whether GitHub accepts the key, whether the installation still exists and grants repositories, whether the App subscribes to the events workflows need, and what GitHub's delivery log says about the last delivery.
